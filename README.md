# Smart-Washroom-Light-Management-System
Automatic washroom lighting system using a PIR sensor, IC 555 timer, BC148 transistors, and a 12V relay. It detects human presence and switches a 230V AC light ON for a preset time. The delay is adjustable using a potentiometer, reducing unnecessary power consumption. Components: IC555, PIR, BC148, relay, diodes, R, C.
